FinancialOutbox is an independently runnable **technical source adapter**, separate from the twelve business APIs. It exposes authenticated V1 financial outbox claim/confirm/fail operations, optional operator/reporting-source routes and health endpoints, using the coordinated financial database and existing lease policy. It runs no broker worker and owns no new database.

Publish with `scripts/Publish-Services.ps1 -IncludeFinancialOutbox -Service FinancialOutbox`. Configure the financial runtime DSN, shared HTTP/OIDC settings, dedicated random service credential and HTTPS listener. Local loopback HTTP requires explicit opt-in. See [transport, configuration and scope](../../../docs/architecture/0021-authenticated-outbox-source-transport.md).

`OperatorServer:Enabled=true` exposes the owner-local JWT message operator boundary described in [0025](../../../docs/architecture/0025-independent-integration-operators.md). `ReportingSourceServer:Enabled=true` exposes the reconciled, durable Purchase/reversal export described in [0027](../../../docs/architecture/0027-reporting-source-export.md). Both are enabled explicitly in Development and default to disabled otherwise. Worker service credentials cannot authorize these operator routes. Source export persistence/service code is in this service's `Infrastructure` folder; source tables remain in `vat_management`.
